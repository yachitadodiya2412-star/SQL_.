📌 Project Overview

Data Digger is a database management project developed using SQL. It demonstrates basic database operations for managing customers, orders, products, and order details.

The project focuses on storing data, modifying records, retrieving information, and analyzing sales data using SQL queries.

🎯 Objectives

Create and manage databases and tables.

Insert, update, and delete records.

Retrieve data using SELECT queries.

Filter records using WHERE conditions.

Perform aggregate calculations using SUM, COUNT, MAX, and MIN.

Sort and group records using ORDER BY and GROUP BY.

Use subqueries to analyze product prices.
